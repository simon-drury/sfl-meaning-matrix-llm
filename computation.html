Architecture: computation over meaning representation

Computation over the Meaning Trajectory

Computation operates over the meaning trajectory itself. Each 3x3 meaning state is flattened to a 9D state that preserves every cell, with no fixed pairing between metafunctions and contextual variables. A causal model reads the states in order and predicts the next meaning state from the states that precede it. Training compares each predicted state with the observed next state in empirical trajectories.
