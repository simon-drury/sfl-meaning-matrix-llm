# KPML/Nigel semantic-input contract

## Purpose

This sandbox investigates one bounded question: can a meaning state produced by the SFL Meaning Matrix system be mapped into the semantic input required by KPML/Nigel, so that Nigel can realise it as English?

The sandbox does not modify the model or replace its existing realisation path. Its first task is to establish KPML/Nigel's own input contract through a native example.

## Academic anchors

- Mann, W. C., & Matthiessen, C. M. I. M. (1983). *Nigel: A Systemic Grammar for Text Generation*. ISI Research Report ISI/RR-83-105, University of Southern California, Information Sciences Institute.
- Bateman, J. A. (1997). Enabling technology for multilingual natural language generation: the KPML development environment. *Natural Language Engineering*, 3(1), 15-55.
- O'Donnell, M. (2008). Demonstration of the UAM CorpusTool for Text and Image Annotation. In *Proceedings of ACL-08: HLT Demo Session* (pp. 13-16).

## Provisional field inventory

The mapping exercise will establish, from the native example rather than assumption, which semantic fields KPML/Nigel requires. Likely areas to inspect include:

- Process type
- Participants and semantic roles
- Circumstances
- Speech function, polarity, and modality
- Tense and aspect
- Theme and information structure
- Identifiability and reference
- Lexical selections

## Mapping ledger

For every field found in the native KPML example, record one status:

- Explicit in the SFL Meaning Matrix state
- Recoverable from the state trajectory or context
- Requires a learned or deterministic mapping
- Not yet represented

## Success criterion

Produce one documented input/output pair in which a selected meaning state is mapped into a valid KPML/Nigel specification and yields grammatical English.
