01 · Proposition

Meaning is a declared state, not only an emergent vector.

The project investigates whether linguistic descriptions from Systemic Functional Linguistics (SFL) can form an explicit front end for language-model processing. Instead of taking subword tokens as the only initial representation, it constructs a compact matrix over metafunction and register.

The research claim is experimental. The repository provides a working prototype and training/inference components; it does not establish that a matrix representation outperforms token-based models. Evaluation against explicit baselines remains the decisive test.

The implementation is deliberately modular. A matrix engine derives structured features, attention and manifold modules operate over those states, an adapter connects them to model-space representations, and a realization component supports the return path to language.

02 · Meaning matrix

Three metafunctions × three register variables.

In SFL terms, the rows concern what language is doing as meaning; the columns concern the contextual configuration in which it is doing it. The matrix is a research representation, not a replacement for the full SFL theory of stratification and instantiation.

Metafunction \ RegisterFieldTenorMode
IdeationalExperiential domain and activityKnowledge/experience positioned between participantsHow experiential content is organized for the channel
InterpersonalStance toward the activity and its demandsRoles, power, solidarity, evaluationExchange configuration in the communicative channel
TextualInformation organization for the fieldAudience-sensitive thematic and cohesive choicesMedium, rhetorical organization, flow

The matrix is flattened or otherwise transformed for downstream numerical operations. It should not be read as claiming fixed one-to-one pairings among SFL categories.

03 · Processing route

From language to a structured state and back.

01

Encode

A clause or prompt is analysed into matrix-relevant features by the matrix engine.

02

Attend

The attention component weights dimensions of the structured representation rather than treating the state solely as an undifferentiated embedding.

03

Traverse

The manifold component supplies geometric operations over meaning trajectories and state movement.

04

Adapt

An adapter projects the structured representation toward a neural model space, preserving a separable SFL-facing interface.

05

Realize and inspect

Realization and visualization modules support language output and inspection of the intermediate representation.

05 · Reproducibility route

Pages documents the work; Python runs it.

GitHub Pages is static hosting, so this reader does not claim to run PyTorch or the project’s server-side components in the browser. Clone the repository and use the project requirements and documentation for the executable research environment.

git clone https://github.com/simon-drury/sfl-meaning-matrix-llm.git
cd sfl-meaning-matrix-llm
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py

The exact command sequence, model/data prerequisites, and operating modes should be checked against README.md, the component READMEs, and workflow definitions in .github/workflows.

06 · Research discipline

What needs to be demonstrated.

Representation validity

Show that annotations or derived matrix states are reliable, interpretable, and appropriate across genres and languages.

Predictive value

Compare against token-only and other structured baselines on predefined tasks, data splits, and metrics.

Engineering value

Measure cost, latency, robustness, controllability, and failure modes rather than inferring advantage from interpretability alone.

The appropriate conclusion at this stage is therefore not that the architecture has displaced tokenization, but that it makes a falsifiable alternative front end available for implementation and evaluation.
