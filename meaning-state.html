Architecture: meaning-state representation

Meaning-State Transition: M0 to M1

The SFL-native preprocessing environment maps incoming language into successive meaning-state matrices. Each matrix organises ideational, interpersonal, and textual metafunctions across field, tenor, and mode as contextual configuration. The figure presents M0 and M1 as distinct configurations separated in semiotic space. Directed vectors run from each element of M0 to the corresponding element of M1, making the delta between states available for inspection.

Repository implementation evidence

  • sfl_matrix_engine.py: maps prompts to M0 and successive deltas as a meaning trajectory.
  • sfl_animate.py: existing trajectory animation prototype.
  • sfl_visualise.py: existing static visualisation prototype.
